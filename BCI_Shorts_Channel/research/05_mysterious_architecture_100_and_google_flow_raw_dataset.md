## 5. Remaining Questions & Gaps (잔여 질문 및 후속 과제)

본 정밀 조사 및 데이터 추출을 완료한 후, 상위 모델이 실제 파이프라인에 반영하기 위해 추가 검토해야 할 잔여 과제 목록입니다.

1. **Google Flow API 정식 지원 여부:**
   - 현재 Google Flow(`labs.google/fx/tools/flow`)는 주로 웹 GUI 환경 중심입니다. 프로덕션 레벨의 완전 자동화를 위해서는 Google Cloud Vertex AI의 Veo API 엔드포인트(Enterprise Private Preview)로 전환할지, 아니면 Playwright/Puppeteer 기반의 Flow 웹 자동화 봇을 구축할지 결정해야 합니다.
2. **Typecast vs Gemini Multi-speaker Native Audio 품질 비교:**
   - '신비한 건축사전' 원작의 정체성인 Typecast '필재' 캐릭터를 영구 유지할 것인지, 아니면 전 과정을 100% 구글 스택으로 통일하기 위해 Gemini 2.0 Flash의 네이티브 오디오 생성(Baritone Voice)으로 완전 대체할 것인지에 대한 청음 A/B 테스트가 필요합니다.
3. **공학 치수선 HUD 오버레이의 자동 생성 고도화:**
   - 붉은색 치수선(`#FF3333`)과 노란색 텔레메트리 게이지(`#FFD700`)를 Veo 프롬프트만으로 렌더링할 때 수치 왜곡 현상이 발생할 수 있습니다. 이를 완벽히 해결하기 위해 Canvas/SVG 기반의 절차적 모션 그래픽 템플릿을 사전 렌더링하여 FFmpeg 오버레이로 합성하는 것이 권장됩니다.
4. **후속 작업 우선순위 제안:**
   - 1순위: 본 보고서의 Part 1(체크리스트) 및 Part 4(구글 스택 아키텍처)를 워크스페이스의 `AGENTS.md` 및 `bci-video-pipeline/SKILL.md`에 영구 규칙으로 동기화.
