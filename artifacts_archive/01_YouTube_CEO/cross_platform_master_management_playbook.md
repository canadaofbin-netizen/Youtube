## 핵심 교정 요약 (1차 초안 대비 반드시 바로잡아야 할 7가지 팩트)

1. **[폐기 ❌] 틱톡 `>60초` 영상에 `1~3%` 트렌딩 음원 삽입 금지**: 메이저 음반사(UMG·Sony·Warner) 상업/트렌딩 음원은 **60.0초 라이선스 상한**이 걸려 있어, `62~86초`인 우리 영상에 `1%` 볼륨으로라도 넣으면 **영상 전체 음소거(내레이션 증발) + `Creator Rewards` 수익화 박탈**이 발생합니다. 100% 자체 오리지널 오디오만 사용해야 합니다.
2. **[폐기 ❌] 유튜브 번인(`102pt` ASS) 쇼츠에 영문 `.srt` 소프트 자막 업로드 금지**: 이미 화면 중앙 하단(`MarginV=521`)에 대형 영문 자막이 박혀 있으므로 `.srt` 업로드 시 `CC`가 켜진 시청자에게 **이중 자막 충돌**이 발생합니다. 유튜브는 `#audio-language = en-US` 설정만으로 `Siren` 음성을 자동 `asr` 색인합니다.
3. **[주의 ⚠️] 유튜브 `Auto-Dubbing` / `MLA`는 번인 영문 자막 쇼츠에서 OFF 권장**: 쇼츠에도 자동 더빙·다국어 오디오가 열렸으나, 화면 한가운데 거대한 영문 자막·영문 차트가 박힌 상태에서 스페인어/한국어 합성 더빙이 나오면 시청각 인지 부조화로 초반 이탈이 증가합니다(클린 플레이트 롱폼 재개 전까지 OFF 유지).
4. **[교정 ❌] 유튜브 `Hype` · `채널 트레일러` · `Test & Compare`는 쇼츠 대상 아님**: 세 기능 모두 **롱폼(`16:9`) 전용**입니다. 또한 데스크톱에서 업로드한 쇼츠 커스텀 썸네일은 **검색·채널 탭·구독 피드에만 노출되고 세로 쇼츠 피드(`87%` 유입)에는 절대 노출되지 않습니다.**
5. **[폐기 ❌] 인스타그램 `Notes(노트)` 완전 제외**: 릴스/피드 Content Notes는 **2025년 4월 공식 폐지**되었고, DM 상단 Notes는 **맞팔로워(`팔로우백한 계정`)에게만 노출**되어 팔로잉 `0`인 크리에이터 계정에서는 도달이 `0`입니다.
6. **[경계 구분 📱] 모바일 앱 전용 vs 데스크톱/API 자동화 가능 영역 분리**:
   - **100% API/데스크톱 자동화 가능**: 유튜브 커뮤니티 `Quiz Post` 예약(`0` 구독자 해금 완료, 프론트엔드 `/channel/<ID>/posts` 경유), 유튜브 `Studio 댓글함(/comments/inbox)` 무재생 하트·대댓글, 인스타 `4:5 (1080×1350)` 무음 캐러셀(`Graph API CAROUSEL` — `3:4`는 API 거부되므로 `4:5` 제작 후 중앙 `3:4` 안전영역 준수), 틱톡 커스텀 커버 + 프로필 상단 고정 3개(`Pin to profile`).
   - **모바일 앱 전용(수동 선택 사항)**: 인스타 스토리 투표/퀴즈 스티커(Graph API는 비즈니스 계정 플랫 이미지만 가능), 인스타 캐러셀 연속 배경음악, 인스타 프로필 고정(`Pin`), 틱톡 `Photo Mode` 업로드·댓글 고정(`Pin comment`)·댓글 영상 답글 스티커.
7. **[해금 조건 명시 ⏳] 팔로워 게이트 기능 대기**: 인스타 `Trial Reels`(`1,000+` 팔로워 해금 후 Graph API `trial_params`로 자동화 가능), 틱톡 `Creator Playlists`(`10,000+` 팔로워 해금 후 데스크톱 `tiktokstudio`에서 자동화 가능).
8. **[보류 ⏸️] 사용자 지정 보류 2건**: 인스타 `댓글 트리거 자동 DM (ManyChat)`, 인스타 `스토리 하이라이트 4폴더`는 구현 범위에서 제외합니다.
