## 1. Active `porcelain_cinematic_v7` Dual-Track Reference Pack (`R66` / `R67`)
Compiles `6–9` `9:16` reference PNGs (`reference_image_specs.json` via `populate_porcelain_reference_contract`) and generates/validates via `ensure_porcelain_reference_pack` (`0-credit` Google Flow `Image` `FLOW_ZERO_CREDIT_IMAGE_MODEL`, `FLOW_ZERO_CREDIT_IMAGE_BATCH_COUNT` batch, `1 -> 2 -> 3` conditioning order) **before** Flow video generation:
- **Track A (`reenactment_track = "track_a"` — `R67` Archival Reenactment)**: For genuine archival experiment footage (`suitable_track_a` or `needs_section_window` via `reenact-extract --section MM:SS-MM:SS`). Extracts quarantined EDL + hashes in `REENACT_QUARANTINE_ROOT`, sanitizes human faces (`YuNet` + CLAHE + HSV skin) & wall text into `9:16` structural guides, renders porcelain `9:16` keyframes (`reenact-refs` / `porcelain-refs`), purges `REENACT_QUARANTINE_ROOT`, and enforces `RQ1–RQ5` (`reenact-qa`).
- **Track B (`reenactment_track = "track_b"` — `R66-Anchor` Scene-Bible Pack)**: For pre-cinema cases (`< MEDIA_MIN_CINEMA_YEAR`) or media rejected by `R44-M` Gates 1–4. Synthesizes `ref_env_master.png` (`order 1`), `ref_cast_<role>.png` (`order 2`, conditioned on `ref_env_master`), `ref_brain_master.png` (`order 1` for `HYBRID`/`NEURO_BIOLOGY`), and `3–5` room-state `ref_anchor_01..05.png` (`order 3`, `scene_id="LOC_<location_id>"`).
- **Selective Anchor-Binding (`PORCELAIN_ANCHOR_MIN_CLIP_RATIO..PORCELAIN_ANCHOR_MAX_CLIP_RATIO`)**:
  - Bound: `porcelain_fullbleed_world` -> matching `(location_id, present_cast_start)` anchor (`strict_room_continuity: True`); `porcelain_living_brain` (except `bounded_micro_channel`) -> `ref_brain_master.png`.
  - Unanchored (`reference_image = None`, prevents wide-frame lock): `porcelain_hands_closeup`, `porcelain_pov_hands`, `porcelain_cutaway_section`, `porcelain_literal_analogy`, `outro`.
- **QA (`main.py ref-qa`)**: Deterministic `Q1–Q10` + provenance (`REF_IMAGE_SOURCES_PRE_GENERATION`, `cv_pre_generation_ready`). Unattended `neuro_diorama` defaults `require_review=False`; pass `--require-review` / `--auto-populate-review` for SHA-256 `reference_semantic_review.json`.
