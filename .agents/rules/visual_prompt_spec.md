## R5 — Monthly Credit Dual-Tier Google Flow Engine (`--engine auto|omni|zero-credit`)
- **Primary Tier (monthly AI credits > 0)**: `FLOW_PRIMARY_VIDEO_MODEL` (`"Omni 1.1 Flash"`, `omni_1_1_flash`).
- **Zero-Credit Video Fallback (credits == 0)**: Auto-switches shard tabs to `FLOW_ZERO_CREDIT_MODEL` (`"Veo 3.1 - Lite [Lower Priority]"`, verified `FLOW_ZERO_CREDIT_TEXT="Generating will use 0 credits"`), scheduling `(n_worker_tabs, zero_credit_output_count)` via `compute_zero_credit_batch_plan` (`n_worker_tabs * zero_credit_output_count <= FLOW_ZERO_CREDIT_MAX_CONCURRENT_RENDERS`, up to `FLOW_ZERO_CREDIT_VIDEO_MAX_BATCH` candidates with CV best-of-batch pick). Never click `Add AI credits`.
- **Zero-Credit Native Flow Image Batching (`DEFAULT_REENACT_IMAGE_BACKEND="flow"`)**: Reference & `R67` keyframes run in Flow `Image` mode (`FLOW_ZERO_CREDIT_IMAGE_MODEL` / `FLOW_ZERO_CREDIT_IMAGE_FAMILY_ID`, `0 credits`) at `FLOW_ZERO_CREDIT_IMAGE_BATCH_COUNT` (`x4`) per prompt, auto-selecting top `Q1–Q7` + `RQ2 dHash` PNG.
- **Workspace & Tab Locks**: Canonical Flow room `AAB_<project_id>` (purge temporary/orphan rooms post-harvest); per-worker `targetId` CDP tab lease (`allocate_dedicated_flow_project_tab`, never touch sibling/user tabs); `compute_clip_target_duration` routes `8s` (diorama/ref-bound) vs `10s` (native-voice Omni). `ALLOW_EXTERNAL_PAID_APIS=False`, `ALLOW_STATIC_IMAGE_VIDEO_FALLBACK=False`.

## R40-A/B/C — Legacy Schema v4 `10`-Clip Composer (`build_flow_prompts`)
- **R40-A Template (`PROMPT_SCENE_WORDS_MIN..PROMPT_SCENE_WORDS_MAX`)**:
  `{FLOW_PROMPT_PREFIX} {3-sentence visual scene}. Voice: {FLOW_VOICE_PROMPT_DESCRIPTOR}. Spoken narration: "{narration}"`
  10-clip arc: `Clip 1 setup` (room + 2-Beat prop action, wide track forward) -> `Clip 2 symptom` (close orbit, cranium `electric cyan-blue` + `crimson-red`) -> `Clip 3 failure` (lateral track, 2-Beat failure) -> `Clip 4 crisis` (cranium dive into bright white studio gallery brain) -> `Clip 5 pivot` (orbit, `warm amber-gold` compensatory route) -> `Clip 6 step1` (macro signal flow) -> `Clip 7 step2` (`crimson-red` crisis junction) -> `Clip 8 step3` (pull-back full circuit) -> `Clip 9 breakthrough` (cranium pull-out to room, `amber-gold` glow) -> `Clip 10 conclusion` (elevated pull-back, `cyan-blue` + `amber-gold`).
- **R40-B Sanitizer & Motion Gate**: `sanitize_prompt_for_flow` strips historical proper names from visual text only; `validate_character_motion` enforces active prop verbs on real-room clips.
- **R40-C `visual_plan.json` Keys (v4)**: `real_environment`, `environment_props`, `scale_anchor_object`, `cast` (`subject`, `others`), `mannequin_actions` (`<= 14w` 2-Beat per room role), `target_region`, `crisis_region`, `crisis_lesion`, `compensatory_region`, `signal_path`, `mechanism_steps`, optional `scenes`.
